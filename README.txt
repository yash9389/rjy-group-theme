RJY GROUP WORDPRESS THEME

A complete step-by-step guide is included as INSTALLATION.md in the theme root.

INSTALLATION
1. In WordPress, open Appearance > Themes > Add New > Upload Theme.
2. Select rjy-group.zip, install it, and activate the theme.
3. Open Appearance > RJY Content Migration and run the migration. It creates missing pages, service records, and the Primary navigation menu without overwriting existing content.

SETUP
1. Open Appearance > Customize > Site Identity and upload the supplied white RJY logo or your latest approved logo.
2. Open Appearance > Customize > RJY Theme Settings to edit colors, hero content, homepage headings, button labels, contact information, images, video, and social links.
3. Edit the generated Primary menu under Appearance > Menus. It matches the React navigation and supports nested dropdowns.
4. Edit Services, Portfolio Projects, and Testimonials in the WordPress dashboard. Use the title, excerpt, editor, featured image, and Order field.
5. Add footer widgets under Appearance > Widgets. The first footer column falls back to the configured office contact details.

CONTACT FORM
The included form stores submissions under Enquiries and sends notifications via wp_mail(). Configure SMTP with your host or an SMTP plugin if needed. Enquiry records are visible only to administrators.

IMAGE CREDITS
All bundled imagery is part of the supplied RJY website design package. Replace any image from the Media Library or theme settings as needed.
